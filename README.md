# 📰 AI Summary for Articles (Chrome Extension)

A Chrome extension that summarizes long articles instantly using **Google Gemini API**.  
Choose between a **Brief Summary**, a **Detailed Summary**, or **Bullet Points** — right inside your browser.

---

## ✨ Features
- 🔹 Summarize any online article in **one click**.  
- 🔹 Choose from 3 styles:
  - **Brief Summary** → 2–3 sentences.  
  - **Detailed Summary** → all main points.  
  - **Bullet Points** → 5–7 concise points.  
- 🔹 Copy summary to clipboard instantly.  
- 🔹 Securely store your Gemini API key in Chrome storage.  
- 🔹 Built with **Manifest V3**, using HTML, CSS, and JavaScript.
